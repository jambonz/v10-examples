# transfer

Examples for transferring a call to another party, using the `dial`, `conference`, and REST APIs.

| Example | Description |
|---------|-------------|
| [blind](./blind) | Immediately bridge the caller to a target by dialing a new outbound leg |
| [warm](./warm) | Dial a target, let them accept or decline, then bridge the caller only on accept |
| [three-way-warm](./three-way-warm) | Put the caller in a conference and dial a specialist into the same room via the REST API |
