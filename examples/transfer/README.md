# transfer

Examples for the packaged `transfer` verb and Live Call Control transfers.

| Example | Description |
|---------|-------------|
| [standalone](./standalone) | The `transfer` verb: blind (refer/dial), warm parked, warm three-way, and no-answer → return |
| [lcc](./lcc) | Live Call Control: park a caller, then inject a transfer mid-call via the REST API |

See also [handoff](../handoff) for Layer-1 transfer-to-human on the `agent` and `llm` verbs.
