# gather

Examples for collecting DTMF and speech input using the `gather` verb.

| Example | Description |
|---------|-------------|
| [dtmf-menu](./dtmf-menu) | IVR menu with DTMF input |
| [echo](./echo) | Speech echo using the default recognizer and synthesizer |
| [echo-deepgramflux](./echo-deepgramflux) | Speech echo using Deepgram Flux for both STT and TTS |
